# krunvm

krunvm is a CLI utility for creating and managing lightweight microVMs from OCI container images. It uses [libkrun](https://github.com/containers/libkrun) as the hypervisor backend and [buildah](https://github.com/containers/buildah) to fetch and mount OCI images as the microVM root filesystem.

Unlike traditional virtual machines, krunvm microVMs boot in milliseconds, require no disk image management, and use the OCI image directly as the root filesystem via a virtio-fs device. Networking is provided by libkrun's Transparent Socket Impersonation (TSI), requiring zero network bridge configuration.

## Supported platforms

| Platform | Architecture | Backend |
|---|---|---|
| Linux | x86\_64 | KVM |
| Linux | AArch64 | KVM |
| macOS | ARM64 | Hypervisor.framework |

<Note>
On macOS, krunvm also supports creating x86\_64 microVMs on AArch64 hosts via Rosetta for Linux (with the `--x86` flag).
</Note>

## How it works

krunvm uses two core dependencies:

- **[buildah](https://github.com/containers/buildah)** — pulls OCI images and mounts them to a local directory, which becomes the microVM root filesystem
- **[libkrun](https://github.com/containers/libkrun)** — provides the lightweight hypervisor that boots the microVM using the mounted rootfs via virtio-fs

The workflow is:
1. `krunvm create <image>` — pulls the OCI image with buildah and stores configuration
2. `krunvm start <name>` — mounts the container and passes the rootfs to libkrun to boot the microVM
3. When the VM exits, the container is unmounted automatically
