## Prerequisites

- krunvm installed — see [Installation](/installation)
- `buildah` installed and available in your `PATH`

<Tabs>
  <Tab title="Linux">
    On Linux you must run all `krunvm` commands inside a `buildah unshare` session. Open a shell session before proceeding:

    ```bash
    buildah unshare
    ```

    <Warning>
      If you run `krunvm` outside a `buildah unshare` session, it will print `Please re-run krunvm inside a "buildah unshare" session` and exit.
    </Warning>
  </Tab>
  <Tab title="macOS">
    On macOS, krunvm requires a case-sensitive APFS volume. If you have not set one up yet, follow the [Installation](/installation) guide before continuing.
  </Tab>
</Tabs>

## Create and run a microVM

<Steps>
  <Step title="Create a microVM from a Fedora image">
    Pull the Fedora OCI image and create a named microVM configuration:

    ```bash
    krunvm create quay.io/fedora/fedora:latest --name my-fedora
    ```

    Expected output:

    ```
    microVM created with name: my-fedora
    ```

    krunvm uses `buildah` to pull the image and store the container configuration. No disk image is created — the OCI image is mounted directly as the root filesystem when the VM starts.

    <Note>
      The `--name` flag assigns a human-readable name to the microVM. If you omit it, krunvm uses the buildah container ID as the name.
    </Note>
  </Step>

  <Step title="Start the microVM">
    Boot the microVM and attach to its console:

    ```bash
    krunvm start my-fedora
    ```

    krunvm mounts the container rootfs and passes it to libkrun, which boots the microVM. Your terminal attaches to the virtio-console inside the guest. The microVM runs the default entry point defined in the OCI image.

    To run a specific command instead of the image default, pass it as an argument:

    ```bash
    krunvm start my-fedora /bin/bash
    ```

    This drops you into a Bash shell running inside the microVM. Type `exit` to stop the VM and return to your host shell.

    <Tip>
      You can pass additional arguments to the command after `--`:

      ```bash
      krunvm start my-fedora /bin/bash -- -c "echo hello from microVM"
      ```
    </Tip>
  </Step>

  <Step title="List your microVMs">
    View all microVMs registered with krunvm:

    ```bash
    krunvm list
    ```

    Example output:

    ```
    NAME          CPUS    RAM (MiB)   SOURCE IMAGE
    my-fedora     2       1024        quay.io/fedora/fedora:latest
    ```
  </Step>

  <Step title="Delete the microVM">
    When you no longer need a microVM, delete it:

    ```bash
    krunvm delete my-fedora
    ```

    This removes the microVM configuration and the associated buildah container. The OCI image layers cached by buildah are left intact.
  </Step>
</Steps>
