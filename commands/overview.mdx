krunvm is controlled entirely through subcommands. Every subcommand accepts `--help` for usage details.

## Global options

<ParamField query="-v" type="number">
  Sets the verbosity level from lowest (0) to highest (5). This flag is accepted before any subcommand.

  ```bash
  krunvm -v 3 start my-vm
  ```

  <Note>
    The `-v` flag is declared in the source but not yet implemented. Passing it currently has no effect.
  </Note>
</ParamField>

## Commands

| Command | Description |
|---|---|
| [`krunvm create`](/commands/create) | Create a new microVM from an OCI image |
| [`krunvm start`](/commands/start) | Start an existing microVM |
| [`krunvm list`](/commands/list) | List all existing microVMs |
| [`krunvm inspect`](/commands/inspect) | Run `buildah inspect` on a microVM's backing container |
| [`krunvm changevm`](/commands/changevm) | Change the configuration of an existing microVM |
| [`krunvm delete`](/commands/delete) | Delete an existing microVM |
| [`krunvm config`](/commands/config) | View or update global default settings |
