---
title: "krunvm list"
description: "List all existing krunvm microVMs and their configuration."
---

## Synopsis

```bash
krunvm list
```

## Description

`krunvm list` prints the configuration of every microVM registered in the krunvm config store. If no microVMs exist, it prints `No microVMs found`.

## Options

<ParamField query="-d" type="boolean">
  Print debug information.

  <Warning>
    This flag is declared in the source but marked as TODO — it is not yet implemented and has no effect.
  </Warning>
</ParamField>

## Output format

For each microVM, `krunvm list` prints one block in the following format:

```
<name>
 CPUs: <n>
 RAM (MiB): <n>
 DNS server: <addr>
 Buildah container: <container-id>
 Workdir: <path>
 Mapped volumes: {"<host_path>": "<guest_path>", ...}
 Mapped ports: {"<host_port>": "<guest_port>", ...}
```

## Example output

## Example
